# Working agreement

- Keep this repository deployable with only documented private inputs.
- Never add real domains, addresses, identities, recipients, certificates, ciphertext, state, or plans.
- Keep `examples/` synthetic and use reserved domains and TEST-NET addresses.
- Prefer native NixOS, OpenTofu, Kubernetes, Flux, and application features.
- Changes to a public interface require an example update and an evaluation or validation check.
- Do not add deployment-specific options until a real private consumer needs them.
